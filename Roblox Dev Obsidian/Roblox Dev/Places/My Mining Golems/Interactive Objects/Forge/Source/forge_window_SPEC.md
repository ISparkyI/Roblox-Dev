# Forge — модальне вікно кузні: специфікація для Roblox

← [[Forge]]

Джерело правди — `gen_forge_window.py` (константи на початку файлу). Превʼю — `forge_window.html`, скриншоти — `shot_asleep.png`, `shot_working.png`, `shot_phone.png`. Стиль — за GDD «2D іконки → Картки покращень і підкладка».

## 0. Загальні правила перенесення
- Усі числа — **одиниці дизайну**. Усе вікно лежить у рамці `ModalRoot` **1120 × 740**, на екран її масштабує **один** `UIScale`.
- Координати нижче: розділ 2 — у `ModalRoot`; розділи 3–8 — у вікні `Window` (його лівий верхній кут = 0,0).
- **Контур:** у SVG лінія по центру краю, тому `stroke-width` у генераторі вдвічі більший. Тут уже вказано **`UIStroke.Thickness`** (половина SVG). Колір контуру завжди **ink `#14161a`**, `ApplyStrokeMode = Border` для рамок, `Contextual` для тексту.
- **Тінь** — суцільна копія форми, зсунута вниз, чорна з прозорістю. Без розмиття, без світіння.
- **Блиск** (gloss) — білий `Frame` з `UICorner`, прозорість указано як «білий N%» (тобто `BackgroundTransparency = 1 − N`).
- **Градієнти** — `UIGradient`, `Rotation = 90` (згори вниз), ключі `offset → колір`.
- **Шрифт:** Heavy = `Font.fromName("Montserrat", Enum.FontWeight.Heavy)` (900), ExtraBold = `…FontWeight.ExtraBold` (800). Колір тексту білий, якщо не сказано інакше.
- **Обведення тексту:** `UIStroke.Thickness ≈ 0,1 × TextSize` (числа дано округлено).
- **Вертикаль тексту:** «центр y» — це середина висоти великих літер (capHeight 0,70 em). У Roblox став `TextLabel` висотою ≈ 1,2 × TextSize з центром у цій точці, `TextYAlignment = Center`; підправ на ±2–4 за скриншотом.
- `ScreenGui`: `IgnoreGuiInset = true`, `ZIndexBehavior = Sibling`, `ResetOnSpawn = false`.

## 1. Масштаб і екран
| Параметр | Значення |
| --- | --- |
| `ModalRoot` | `Frame`, прозорий, `Size = (0,1120, 0,740)`, `AnchorPoint = (0.5, 0.5)`, `Position = (0.5,0, 0.5,0)` |
| `UIScale.Scale` (ПК) | `min((vw − 48) / 1120, (vh − 32) / 740)` → 1280×720: **0,93** |
| `UIScale.Scale` (телефон) | `min((vw − 24) / 1120, (vh − 16) / 740)` → 844×390: **≈ 0,505** |
| Вибір | телефон, якщо `vh < 500` (або `TouchEnabled` і немає миші). Перераховувати на `ViewportSize` changed |
| Мінімальний текст | 20 одиниць → ≈ 10 px на телефоні. Дрібніше в цьому вікні не робимо |
| Backdrop | `Frame` на весь екран під `ModalRoot`, `#000000`, `BackgroundTransparency = 0.45` (видно на 55%), `Active = true` (ловить кліки) |

> Поп-анімація на піку 1,05 на мить виходить за поля на 1–2 px — це нормально.

## 9. Анімації
| Подія | Що | Час | Easing |
| --- | --- | --- | --- |
| Відкриття | `Backdrop.BackgroundTransparency` 1 → 0.45 | 0,20 с | Linear |
| | `Pop.UIScale` 0.85 → 1.05 | 0,15 с | Quad Out |
| | потім 1.05 → 1.00 | 0,10 с | Quad InOut |
| Закриття (X або гравець вийшов з кільця) | `Pop.UIScale` 1 → 0.85, `Backdrop` 0.45 → 1 | 0,12 с | Quad In; потім `Visible = false` |
| Наведення на кнопку | `UIScale` кнопки 1 → 1.04 | 0,10 с | Quad Out |
| Натискання | 0.92, потім пружно до 1 | 0,20 с | Back Out |
| Тьмяна кнопка натиснута | хитання по x: −10, +10, −7, +7, −3, 0 | по 0,03 с | Linear |
| Шкали при зміні значення | ширина заливки до нової | 0,25 с | Quad Out |

Для плавного зникнення всього вікна `Pop` можна зробити `CanvasGroup` і вести `GroupTransparency 0 → 1` разом зі зменшенням (на слабких телефонах — лише масштаб).

## 11. Дерево інстансів (скорочено)
```
ForgeGui (ScreenGui, IgnoreGuiInset)
├─ Backdrop (Frame)
└─ ModalRoot (Frame 1120×740) + UIScale(fit)
   └─ Pop (Frame) + UIScale(anim)
      ├─ WindowShadow
      ├─ Window (обідок) ─ RimLine, Panel(+Studs, Shade)
      │   ├─ Row1 (UIListLayout) ─ Chip×1..3, Message
      │   ├─ Row2 ─ Label, Bar(Track, Fill, Gloss, Text), TestButton
      │   ├─ OreRow×3 ─ Tile(Icon, Check), Name, Sub, Bar | BarsText, IngotTile
      │   ├─ Overlay (Visible лише при переходах) ─ Text, Bar
      │   └─ ButtonLeft, ButtonRight (+Shadow, Gloss, Text, UIScale)
      ├─ TitleShadow, Title
      └─ CloseShadow, Close (+ 4 смужки хреста)
```
Без studs ≈ 150 інстансів; зі studs з рамок ще ≈ 750 (або 1 `ImageLabel` Tile).

- All → повзунок на M (руду не кладе); Put N → `ForgeAction:FireServer("PutOre", { ore = ключ, n = N })`; сервер обмежує n запасом і місцем.
- Клавіші: ← ↓ −1, → ↑ +1, Enter — Put N, Esc — закрити. Дані оновлюються з кузні кожні 0,15 с; якщо класти вже нема чого або голем не працює — попап закривається.
