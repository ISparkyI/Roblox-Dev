# Interactive Objects

← [[My Mining Golems]]

Інтерактивні об'єкти плейсу: те, з чим гравець взаємодіє (підказка [E], кліки, анімація), разом з моделлю і скриптом. Кожен об'єкт — окрема папка з нотаткою, генератором моделі (`Source/`) і прев'ю (`Preview/`), щоб його можна було швидко поставити в будь-яку нішу, префаб чи інший плейс.

| Об'єкт | Що робить | Статус |
| --- | --- | --- |
| [[Roll Station]] | станція ролу: пульт з похилим екраном (вибір типу голема Miner / Carrier / Warrior — MAP 2), лампи, тумба з важелем; E · ROLL → ривок важеля, подія `Pulled(player, role)` | у грі (без системи ролу) |
| [[Cave Entrance]] | вхід у печеру големів: горб з темним проходом, жовте коло, напис CAVE, кнопка E · ENTER CAVE (затиск 0,9 с → телепорт у печеру ніші) | у грі |
| [[Roll Lever]] | **замінено станцією ролу (Roll Station)**; старий важіль — бекап `NicheBackup/RollLeverModel_old_v1` | архів |
| [[Forge]] | кузня з големом-ковалем: коло з вікном, пробудження рудою мапи + $1 000, переплавка руди в злитки (вугілля не плавиться), піддони Ore / Bars з моделями в стилі жил, апгрейдер | у грі |
| [[Sell Shop]] | лавка скупщика: голем-продавець Наґґет (дворф), зелене коло SELL, ваги, рахівниця, вагонетка, дошка цін мапи; анімації спокою, вітання, продажу, прощання | у грі (модель, анімації, вікно продажу) |
| [[Plots]] | зони фарму в ніші (6, купуються 1 → 6): руда росте на очах, HP-бар, големи-майнери, носій з ящичком, світні стаки ×N, ящик плоту з кнопкою COLLECT, табло прокачки (8 карток, Auto Sell — MAP 2), розстановка Place Golems | у грі |
| [[Roll Upgrades Screen]] | табло покращень ролу: коли власник зупиняється біля важеля й стоїть 1 с, падає зі стелі на ланцюгах; відійшов — піднімається | у грі (картки Roll Luck, Roll Stands) |
| Mutation Machine | дві машини по центру зали: 3 входи → камера з реактором і блискавками → 1 вихід; E · PLACE / TAKE / CLAIM, START і xN TIME на панелі над машиною; локальні для кожного гравця ([[GDD - Mutation Machine]]) | у грі |
| Diamonds Shop / Events Shop | дві лавки в кінці зали з големами-братами, коло → вікно магазину ([[GDD - Diamonds Shop]]) | у грі (Events — COMING SOON) |
| Plot Stats | особисте табло статистики біля входу в нішу (модель `PlotStats` у шаблоні ніші) ([[GDD - Leaderboards]]) | у грі |

**Як додати новий об'єкт:** папка `<Назва>/` з нотаткою `<Назва>.md` (рядок `← [[Interactive Objects]]`), рядок у таблицю вище, генератор у `Source/`, знімок у `Preview/`.

**Підказки E** усіх об'єктів — свої (`Style = Custom`), малює `StarterPlayerScripts/CustomPrompts`; атрибути описані в [[Cave Entrance]].
