# Wooden Golem

← [[Golems]]

*Дерев'яний голем.* Перший голем гравця (1 до 1, безкоштовний). Моделі ще немає: чекаємо референс-картку.

## Стиль для референсу
| Поле | Опис |
| --- | --- |
| Матеріал / тема | старий дуб, кора, мох; простий трудяга-новачок |
| Силует | трохи нижчий і худіший за Stone Golem, руки-колоди, ноги-пеньки |
| Палітра | дерево `#a0703f`, кора `#6b4423`, світле дерево `#c8955a`, листя `#5fa34a` + спільні `#f1f5f8`, `#1c2836`, `#f2a0b4` |
| Фірмові деталі | паросток з 2–3 листків на голові; річні кільця на зрізах плечей; плями моху на колінах |
| Обличчя | великі очі, трохи насуплені брови, маленький рот |
| Меч | лезо зі струганої дошки, гарда-брусок, руків'я обмотане лозою |
| Кірка | загострений брусок як голова кірки, прив'язаний лозою до кривого держака |
| Ящик | грубий ящик з дощок, кутики темніші, мотузяні ручки |
| Не робити | не робити його «зеленим лісовим» (листя тільки акцент), без дрібних гілочок |
