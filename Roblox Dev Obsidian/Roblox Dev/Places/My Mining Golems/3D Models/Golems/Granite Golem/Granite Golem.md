# Granite Golem

← [[Golems]]

*Гранітний вартовий.* Дев'ятий голем каталогу (ID `granite`, Uncommon, рол 1 до 300, ціна майнера 18 500, шкода 15, швидкість 1.05, `size = 1.15`). Полірований рожево-сірий граніт з чорно-білими вкрапленнями: спокійний монументальний вартовий, схожий на вирізьблену статую. Зроблено одразу за командою користувача, без окремого плану.

## Маси
1. **Ноги:** темні гранітні стопи, гомілки з полірованим різьбленим пояском, вкраплення.
2. **Таз** темний, поверх — полірований пояс.
3. **Корпус** монументальний: на грудях полірована плита з темною ромбовою «емблемою», на спині темна плита; чорно-білі вкраплення спереду й ззаду.
4. **Голова:** квадратна, зверху «капітель» — полірована плита й гранітна верхівка, як у колони; вкраплення з боків.
5. **Руки:** темні наплічники з полірованими пластинами, поліровані наручі, темні кулаки з гранітними кісточками й полірованим обідком.

## Стиль для референсу
| Поле | Опис |
| --- | --- |
| Матеріал / тема | полірований рожево-сірий граніт з чорно-білими вкрапленнями; спокійний монументальний вартовий-статуя |
| Силует | прямий, широкий, як вирізьблений моноліт: голова з капітеллю, квадратні наплічники, різьблені пояски |

| Обличчя | великі очі, прямі темні брови, рівний спокійний рот, рожеві щічки |
| Меч | гранітне лезо з полірованою кромкою, темний дол, чорно-білі вкраплення на лезі, темна гарда з полірованою смугою |
| Кірка | гранітна голова з вкрапленнями, поліровані леза, темний держак |
| Ящик | гранітний ящик з полірованим обідком і вкрапленнями |
| Не робити | оранжевий відтінок (Clay), синюватий камінь (Stone), камінці-галька (Gravel), округлі форми |

## Перевірка в Play (01.11.2026)
- **Плот:** Granite-майнер (Normal), масштаб 1,15, б'є вугільну й мідну руду; точки удару `HitPoint` усередині руди (зсуви −2,13 / 0,71 / 0,59; −1,89 / −0,25 / −0,69; −2,02 / 0,50 / −0,46 при пів-розмірах 3,76 / 2,43 / 3,07 і 4,58 / 2,79 / 3,70). Носій (Silver) масштабу 1,15 з ящиком.
- **Воїн у руці:** фігурка Granite (Void) з мечем, табличка «Void [x5] · Uncommon · Granite Golem · 65 dmg · 900 HP · Cost: $135,000».
- **Index:** вкладка Normal, секція Uncommon — Granite Golem відкритий (1 in 300, +1 діамант, Claim).
- **Рол:** `GolemModel.has("granite") = true`, `GolemModel.build` для трьох класів — масштаб 1,15.
- Помилок гри в консолі немає.
- **Не перевірено окремо:** вікно інвентаря, рол важелем, стенд печери.
