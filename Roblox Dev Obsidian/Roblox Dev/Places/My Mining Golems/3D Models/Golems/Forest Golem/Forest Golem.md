# Forest Golem

← [[Golems]]

*Лісовий голем.*

![[forest_golem_preview.png]]

Дружній дерев'яний голем, зарослий листям і мохом. Модель зроблена за концепт-листом:

![[forest_golem_concept.png]]

| Параметр | Значення |
| --- | --- |
| Блоків | 59 |
| Трикутників | 708 |
| Кольорів | 7 (див. примітку) |
| Правило 0,1 | виправлено 24 грані, 0 збігів |
| Розмір (од. моделі) | 13,2 × 15,1 × 5,3 |
| Розмір (стади) | 6,6 × 7,6 × 2,7 |
| Точка опори | центр X/Z, низ на Y = 0 |
| Валідатор glTF | 0 помилок, 0 попереджень |

## Маси
1. **Ноги:** ступня, гомілка, стегно. Спереду латка листя, ззаду помаранчева плита, збоку мох.
2. **Таз.**
3. **Корпус:** торс і широкі плечі. Спереду помаранчеві груди, на спині листова плита й мох.
4. **Голова:** велика, з мордою, що виступає вперед. Згори листяна шапка з трьома паростками, з боків листки-«вуха».
5. **Руки:** довгі, до колін. Плече з листовою накладкою, передпліччя з латкою листя, кулак із пальцями та великим пальцем.

> [!warning] 7 кольорів
> Концепт-лист має 6 кольорів, але зіниць у ньому немає в палітрі. Для зіниць узято спільний темний колір гри, тому кольорів 7, а GDD дозволяє до 6. Якщо треба вкластися в ліміт, зіниці можна зробити темним деревом `#6f4e37`.

## Обличчя
- Око складається з 4 шарів, кожен виступає на 0,1: білок, райдужка, зіниця, блиск. Розмір 1,6 × 1,7, це близько 47% висоти голови.
- Брови зроблені з листя й нахилені вгору до центру на 0,15 рад, тож вираз дружній.
- Щічки — зелені пластинки.
- Рот — проста усмішка на морді: темна смужка й два кутики трохи вище. Колір той самий, що в зіниць, тож нового кольору не додано.
- З нахилом стоять брови, паростки й бокові листки. Автоматична перевірка правила 0,1 їх пропускає, тому їх треба оглянути оком.

## Анімації
Скелет має 24 кістки. Кожен блок прив'язаний до однієї кістки, тому блоки не гнуться. Порівняно з кам'яним големом додано кістки для паростків (`Leaves`), бокових листків (`SideLeaf_R`, `SideLeaf_L`) і рота (`Mouth`, `MouthCorner_R`, `MouthCorner_L`).

| Кліп | Тривалість | Що робить |
| --- | --- | --- |
| Idle | 3,0 с | погойдується, як дерево на вітрі, з цікавістю нахиляє голову, листя тріпочеться |
| Walk | 1,4 с | іде перевальцем: таз перекочується на опорну ногу, руки бовтаються із запізненням |
| Run | 0,8 с | пригинається й нахиляється вперед, листя притискається назад від вітру |
| Face | 4,5 с | кліпає (одинарно й подвійно), роззирається й ширше усміхається, «бурмоче» (рот двічі відкривається), на мить дивується з ротом «О» |

Face чіпає лише очі, зіниці, брови й рот. Його треба вмикати **одночасно** з Idle, Walk чи Run.

## Структура папки
- `Roblox/`: тільки те, що йде в Roblox Studio (Import 3D)
  - `ForestGolem_Animated.glb`: основна модель зі скелетом і анімаціями
  - `ForestGolem_Static.glb`: та сама модель без скелета, для декорацій
- `Preview/`: переглядач анімацій (`forest_golem_animations.html`), прев'ю і концепт-лист
- `Source/`: скрипти, з яких зібрана модель. Спочатку `forest_golem_generator.py`, потім `forest_golem_rig.py`
