# Stone Golem

← [[Golems]]

*Кам'яний голем.*

![[stone_golem_preview.png]]

Сердитий кам'яний голем у блоковому стилі. У грудях у нього кристал-серце, з плечей і спини ростуть кристали.

**v2:** модель перероблено за розділом GDD стилю «Повороти для округлення і живості». Кінцівки, наплічники й плити повернуті на невеликі кути (дзеркально для L/R), тому голем виглядає органічніше. Обличчя лишилося рівним.

| Параметр | Значення |
| --- | --- |
| Блоків | 52 (повернутих: 36) |
| Трикутників | 624 |
| Кольорів | 6 |
| Правило 0,1 | виправлено 19 граней, 0 збігів; повернуті з однаковою орієнтацією: 0 збігів |
| Розмір (од. моделі) | 14,16 × 13,36 × 6,84 |
| Розмір (стади) | 7,1 × 6,7 × 3,4 |
| Точка опори | центр X/Z, низ на Y = 0 |
| Валідатор glTF | 0 помилок, 0 попереджень (Static і Animated) |

## Що змінилося у v2
| Деталь | Поворот | Навіщо |
| --- | --- | --- |
| Стопи | ±0,10 рад навколо Y (носки назовні) | природна важка стійка |
| Носки (`Toe`) | новий блок, 45° навколо Y | округлений носок |
| Гомілки, стегна | ±0,06 / ∓0,10 навколо Y | кінцівки не стоять однаковою сіткою |
| Наколінники | −0,22 рад нахил | лягають на коліно, а не стирчать пластиною |
| Наплічники | −0,22 рад нахил назовні + верхня плита (0,45 навколо Y) | масивні округлі плечі |
| Кристали на плечах і спині | 0,3…0,6 рад, нові блоки | «кристали ростуть з каменю», характер |
| Кристал-серце | ромб (45° навколо Z) | виразніший акцент |
| Кам'яна шапка (`HeadCap`) | 0,35 навколо Y, нахил 0,10 | голова не плоска зверху |
| Задні плити | 0,04…0,10 нахил | живіша спина |
| Плечі, передпліччя, кулаки | ±0,08 / ∓0,10 / ±0,12 навколо Y | руки не паралельні корпусу |
| Налікотники, кісточки | разом зі своїм батьком (передпліччя, кулак) | деталь сидить на масі |
| Обличчя | без змін | рівне й дзеркальне за GDD стилю |

## Маси
1. **Ноги:** стопа з округленим носком, гомілка з наколінником, стегно.
2. **Таз.**
3. **Корпус:** торс і груди. Спереду плита з кристалом-ромбом, на спині дві плити і три кристали.
4. **Голова:** невелика, втоплена в плечі, з кам'яною шапкою, важким надбрівним виступом і щелепою.
5. **Руки:** плече з наплічником (верхня плита + кристал), передпліччя з налікотником, великий кулак з кісточками.

## Обличчя
- Очі 1,1 × 1,1 (~38% висоти голови) зібрані шарами по 0,1: білок, зіниця, блиск.
- Брови нахилені вниз до центру на 0,35 рад, тому голем сердитий.

| Поле | Опис |

| Матеріал / тема | сірий камінь з кристалами; сердитий, але милий |
| Силует | масивні плечі з наплічниками, велика грудна клітка, маленька голова, втоплена в плечі |
| Палітра | `#8b96a3`, `#66717e`, кристал `#6fd3e0` + спільні `#f1f5f8`, `#1c2836`, `#f2a0b4` |
| Фірмові деталі | кристал-ромб у грудях, кристали на плечах і спині, кам'яна шапка |
| Обличчя | сердиті брови, нахилені до центру, великі очі |

## Скелет і анімації
Скелет має 18 кісток. Кожен блок прив'язаний до однієї кістки, тому під час руху блоки не гнуться. Нові блоки v2 прив'язані так: носки й наколінники до гомілки, шапка до голови, кристали й наплічники до корпусу.

| Кліп | Тривалість | Що робить |
| --- | --- | --- |
| Idle | 2,4 с | дихання, легке похитування головою й руками |
| Walk | 1,2 с | важкий крок, руки в протифазі до ніг, поворот корпусу |
| Run | 0,7 с | нахил уперед, широкий крок, зігнуті руки |
| Face | 4,0 с | кліпання, погляд вбік, брови «хмик» і підйом; грає поверх будь-якого кліпу |
| Mine | 1,4 с | удар інструментом: стійка → замах над головою (0,45 с) → удар з прискоренням (0,62 с) → віддача (0,74 с) → повернення |

- Кліпи Idle/Walk/Run/Face є і в `StoneGolem_Animated.glb`. Кліп Mine є тільки в Luau-аніматорі плейсу.
- **Тримання інструмента:** кулак `Fist_L` (права рука голема, бо він дивиться в −Z). Інструмент кріпиться до кістки `Forearm_L`, точка хвату — центр кулака (−5,3; 3,7; 0,34) у координатах моделі.
- Кути пози удару підібрано скриптом `Source/solve_strike.py` під ціль на відстані 5 стадів перед големом.

## Roblox
- Модель збирається з Part за даними `GolemData` (палітра, кістки, блоки з повним `CFrame`). У Studio вона називається `StoneGolem`.
- **Studs:** на 40 деталях тіла `Texture` з асетами Resurface: `StudsPerTile 0.25`, `Transparency 0.2` (видно на 80%), `Color3` як у деталі. Без studs лишаються `Root` і деталі обличчя (очі, зіниці, блиск, брови, рот, щічки, блиск кристала).

## Структура папки
- `Roblox/StoneGolem_Animated.glb`: модель зі скелетом і кліпами Idle/Walk/Run/Face
- `Roblox/StoneGolem_Static.glb`: та сама модель без скелета
- `Source/golem_generator_v2.py`: генератор v2 (ієрархія блоків, повороти, правило 0,1, GLB, звіт)
- `Source/golem_rig_v2.py`: скелет і анімації (`StoneGolem_Animated.glb`)
- `Source/render_preview.py`: прев'ю спереду і ззаду
- `Source/solve_strike.py`: підбір кутів пози удару
- `Source/v1/`, `Preview/v1/`: перша версія (42 блоки рівно по осях)
