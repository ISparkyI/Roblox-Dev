# Golem Reference GDD

← [[Golems]]

Універсальний шаблон для **будь-якого голема** плейсу. За ним ми готуємо референс-картку для AI-генератора картинок, а потім Claude за цією карткою будує 3D-модель, 3 предмети і анімації.

## Процес
1. **Опис стилю голема.** У нотатці голема заповнюємо розділ «Стиль для референсу» за шаблоном нижче.
2. **Промпт.** Підставляємо опис у промпт (розділ «Промпт для генератора»).
3. **Генерація.** Гравець генерує картку в AI-генераторі. Якщо щось не так, генерує ще раз або окремо дотягує предмети.
4. **Референс у базу.** Готові картинки кладемо в `<Голем>/Reference/` і передаємо Claude.
5. **Модель.** Claude будує голема в блоковому стилі (блоки, повороти, правило 0,1, studs через Resurface), 3 предмети й анімації за таблицями нижче. Результат описується в нотатці голема.

## Референс-картка
Одна картинка 16:9, нейтральний світло-сірий фон, рівне м'яке світло, без тіней на фоні, без тексту, крім підписів видів.

| Ряд | Що на ньому |
| --- | --- |
| Верхній | голем у 4 видах в одному масштабі, нейтральна поза (T-поза не потрібна, руки трохи від тіла): **спереду**, **3/4 спереду**, **збоку (справа)**, **ззаду** |
| Нижній | 3 предмети голема, кожен у виді 3/4 і збоку: **меч** (воїн), **кірка** (майнер), **ящик** (носій) |
| Праворуч унизу | палітра: 4–6 кольорових плашок |

**Правила для картинки:**
- Усе зібрано з **прямокутних блоків** (воксельно-блоковий стиль, як іграшкові цеглинки), без округлих форм і без дрібних деталей.
- Кольори рівні, без текстур і градієнтів (studs додамо самі в Roblox).
- Масивний низ і плечі, невелика голова, втоплена в плечі. Великі очі.
- Предмети в масштабі голема: кірка й меч приблизно до пояса, ящик у дві долоні.
- Усі 4 види голема — **та сама** модель (однакові пропорції й деталі).

## Шаблон опису стилю (в нотатці голема)
| Поле | Що писати |
| --- | --- |
| Матеріал / тема | з чого голем (дерево, камінь, лава…) і настрій |
| Силует | пропорції, що виділяє силует (широкі плечі, горб, роги…) |
| Палітра | 3–4 власні HEX + спільні: світлий `#f1f5f8`, темний `#1c2836`, рожевий `#f2a0b4` |
| Фірмові деталі | 2–4 деталі, за якими голема впізнають (кристали, листя, тріщини…) |
| Обличчя | вираз, брови, рот |
| Меч | форма леза, руків'я, матеріал |
| Кірка | форма голови кірки, держак, матеріал |
| Ящик | форма, матеріал, кріплення |
| Не робити | що зіпсує стиль саме цього голема |

## Що будує Claude
**Модель:** блоковий стиль, до 1 000 трикутників, низ на Y = 0, обличчя в +Z моделі. Скелет з однакових кісток для всіх големів, щоб анімації можна було переносити.

**Предмети:** меч, кірка, ящик — окремі групи блоків. Кожен має точку хвату: меч і кірка в правому кулаці, ящик — двома руками перед грудьми.

**Анімації:**

| Підклас | Кліп | Що робить | Подія |
| --- | --- | --- | --- |
| усі | Idle | дихання, похитування | — |
| усі | Walk / Run | важкий крок / біг з нахилом | — |
| усі | Face | кліпання, брови (поверх інших) | — |
| Майнер | Mine | замах і удар кіркою по руді | `Hit` у момент удару |
| Носій | PickUp | нахил, підняти руду / ящик | `Grab` |
| Носій | Walk / Run з ящиком | руки тримають ящик, корпус рівніший | — |
| Носій | Drop | поставити руду в ящик зони | `Release` |
| Носій | Idle (ящик повний) | стоїть з ящиком, нетерпляче постукує ногою | — |
| Воїн | Attack | замах і удар мечем | `Hit` |
| Воїн | Idle бойовий | стійка з мечем | — |

**Масштаб часу мутацією:** усі робочі кліпи грають з `AnimSpeed`:
- майнер і воїн: `Інтервал_Normal / Інтервал_мутації`;
- носій: `Швидкість_мутації / Швидкість_Normal`.

Подія удару (`Hit`) лежить на тій самій частці кліпу, тому шкода завжди збігається з анімацією.
