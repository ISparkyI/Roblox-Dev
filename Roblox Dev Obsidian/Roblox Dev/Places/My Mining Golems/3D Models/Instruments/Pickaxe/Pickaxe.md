# Pickaxe

← [[Instruments]]

*Кірка.*

![[pickaxe_preview.png]]

Кірка в блоковому стилі. Генератор будує блоки ієрархічно, повороти взято з розділу GDD стилю «Повороти для округлення і живості». Робоче лезо зібране з 4 сходинок, кожна наступна нахилена сильніше, тому лезо вигинається дугою. Зворотне лезо коротке, з лопаткою. Голову округлено блоком, повернутим на 45°.

| Параметр | Значення |
| --- | --- |
| Блоків | 15 |
| Трикутників | 180 |
| Кольорів | 5 |
| Правило 0,1 | 0 збігів серед блоків з однаковою орієнтацією |
| Розмір (од. моделі) | 1,56 × 11 × 8,45 |
| Розмір (стади) | 0,8 × 5,5 × 4,2 |
| Точка опори | місце хвату (0, 0, 0) |
| Осі | +Y — держак до голови, +Z — робоче лезо |
| Кінчик леза (лок.) | (0; 6,49; 5,15), блок `Pick4`, його +Z кінець |
| Валідатор glTF | 0 помилок, 0 попереджень |

## Блоки
1. **Держак:** дерев'яний, від −1,4 до 7,8 по Y. Має обмотку-хват (темне дерево, поворот 0,2) і кільце (поворот 0,55).
2. **Навершя:** темний метал, ромбом (0,78).
3. **Голова:** блок + округлювач на 45° + верхня шапка.
4. **Робоче лезо:** 4 сегменти з нахилом 0,10 → 0,32 → 0,55 → 0,80 рад. Сегменти звужуються до кінчика, на другому є блиск.
5. **Зворотне лезо:** 2 сегменти (0,10 → 0,40) і лопатка.

## Як використовувати
- **Хват:** точка опори моделі — це місце хвату. Щоб дати кірку персонажу, точку опори ставлять у центр його кулака і прив'язують блоки до кістки передпліччя.
- **Орієнтація в руці:** держак уздовж передпліччя вперед, лезо вниз, наприклад `Rx(π/2 + нахил)`. Нахил від −0,2 до 0,5 визначає, наскільки держак піднятий.
- **Точка удару:** кінчик робочого леза. Персонаж, що б'є, може брати її як `Pick4.CFrame * (0, 0, Size.Z/2)`.
- **Roblox:** 15 Part, Anchored, без колізії (інструмент не штовхає інші об'єкти).
- **Studs:** `Texture` з асетами Resurface, `StudsPerTile 0.25`, `Transparency 0.2` (видно на 80%), `Color3` як у деталі. На блиску studs немає.
