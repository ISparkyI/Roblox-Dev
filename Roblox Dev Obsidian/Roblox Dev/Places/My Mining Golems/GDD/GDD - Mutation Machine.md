# GDD - Mutation Machine

← [[My Mining Golems - GDD|GDD]]

Машина злиття: 3 однакових голема → 1 з наступною мутацією.

## Mutation Machine
- **3 однакових голема з однаковою мутацією → 1 голем з наступною мутацією** (наприклад, 3 × Gold → 1 × Diamond).
- *(Пропозиція: «однакові» означає ту саму назву голема, той самий клас і ту саму мутацію.)*

| Покращення | Час |
| --- | --- |
| Normal → Bronze | 15 хв |
| Bronze → Silver | 30 хв |
| Silver → Gold | 2 год |
| Gold → Diamond | 8 год |
| Diamond → Void | 20 год |
| Void → Rainbow | 60 год |
| Rainbow → Secret | 120 год |

- Геймпас прискорення за Robux: ×2 / ×4 / ×8 …, час ділиться на множник.
- Таймер іде, навіть коли гравець не в грі (рахується від часу старту).

## У грі (29.10.2026)
Реалізовано: `ServerScriptService/MutationService`, `StarterPlayerScripts/MutationMachineClient`, `Shared/MutationConfig` (таймери, формули часу). Бекап — `NicheBackup/MutMachine_v1`.

**Де:** `Workspace/Cave/Hub/MutationMachines/Machine1..2` — дві машини по центру проходу обабіч Marketplace (місце вибрав користувач, потім пересунув сам). Кожна — довга платформа: **3 входи** з одного боку, камера посередині, **1 вихід** з іншого (жовта арка). Зверху камери — реактор зі скляною колбою й кулею, 4 котушки, антена; мідні труби від входів до камери, стрілки на палубі в бік виходу. Неону мінімум (користувач: «не так світився»): лише куля реактора, кінчик антени й блискавки.

**Як грати:**
- Голем у руці → **E** на вхідному слоті — PLACE (голем зникає з інвентаря, запис з тим самим UID лежить у машині). Умови: не на плоті, не Secret, такий самий (назва + клас + мутація), як уже покладені в цю машину.
- **E** на зайнятому слоті — TAKE: голем назад в інвентар (і в руку), мутація скасовується, таймер скидається.
- 3 однакових покладено — на панелі кнопка **START** (запуск — `Remotes/MutationAction` "Start"). Сам не стартує (рішення користувача).
- Час минув — вхідні слоти порожні, на виході стоїть голем з наступною мутацією; **E · CLAIM** (на виході або на будь-якому вході): 3 записи спалюються (`GolemRegistry.Burn` "mutate"), новий голем (новий UID) — в інвентар, хотбар і руку. Інвентар повний — сіра INVENTORY FULL.
- Машини **локальні**: кожен гравець бачить лише своїх големів, свою панель і таймер. Дві машини — дві мутації одночасно.

**Панель над машиною** — SurfaceGui на невидимій дошці `PanelBoard` (обидва боки, фіксована роздільність, текст не смикається при наближенні камери): MUTATION MACHINE N, статус (ADD 3 GOLEMS / ADD N MORE / PRESS START! / MUTATING... / READY!), «Added: <голем> · <мутація> [n/3]», великий таймер, смуга прогресу з %, «<з> → <до>», SPEED xN · ціна наступного ступеня, кнопка **xN TIME**. `PanelBoard.CanQuery = true` — інакше кнопки не клікаються.

**Ефекти (клієнт):** фіолетові блискавки від котушок до антени час від часу (під час мутації — частіше, інколи подвійні), частинки в реакторі під час мутації, колір екранів камери й кулі — за мутацією-ціллю; таблички над големами (мутація з переливом + назва), аури мутацій.

**Таймер:** job = { dur, done, t0, mult }, час — `workspace:GetServerTimeNow()` (іде й офлайн). Збереження — секція `Mutation` у DataService (не скидається на новій мапі). id големів у машинах враховує `CaveStandService.MaxId`.

**Прискорення (Fast Mutations):** ступінь `MutSpeedTier` — на гравця, тобто **діє на обидві машини одразу**. Купівля під час мутації: пройдене зараховується за старим множником, решта йде з новим. Кнопка xN TIME — Developer Product наступного ступеня (x2 → x3 → x4 → x8 … x1024, далі сіра MAX SPEED). ID — [[GDD - Monetization]].
