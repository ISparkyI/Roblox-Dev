# Map Style Guide — як робити ніші нових мап

← [[Plans]] · [[GDD - Maps]] · [[GDD - Map Prefabs]] · [[Niche Stage 3]] · [[Plan - Map 3 Crystal Depths Prefab]]

Зведення рішень користувача під час роботи над мапою 3 «Crystal Depths» (04.11.2026). Мапа 3 — еталон для мап 4–6.

## 0. Як підключається мапа
- Префаб: `Workspace/NichePrefabs/NichePrefab_Stage<N>` (у грі NicheService переносить папку в ServerStorage і клонує в нішу гравця при переході).
- Основа — копія префабу попередньої мапи, поставлена в ряд (Z + 185.4). Атрибут моделі `Stage = N`.
- Увімкнути: `ForgeConfig.MAX_STAGE = N`. Руда, ціни, Workshop (WAKE), моделі жил/шматків/злитків/Cut уже в конфігах і `ReplicatedStorage/PlotAssets`, `Prefabs/ForgeProps`.
- Тест: Play → сервер `ServerScriptService.MapService.Advance:Invoke(player, true)` до потрібної мапи; перевірити руду на плотах, табличку, консоль.
- Табличка входу: текст `Stage` у SurfaceGui OwnerSign статичний у префабі → змінити на «Map N · Назва».

## 1. Загальний стиль (обов'язково)
- **Тільки студси**: `Material = Plastic`, `MaterialVariant = "Studs"`. Ніякого мармуру, Slate, Metal, Glass, ForceField.
- **Ніяких круглих форм** (Cylinder, арки, кола) — лише прямокутні блоки. Якщо щось нестандартне — підлаштовувати стіни/стелю під нього.
- **Ніяких накладань текстур**: деталі стикуються, а не заходять одна в одну (крім кріплення до стіни на ~0.3 стада). Перед завершенням — перевірка перетинів (`GetPartsInPart` / AABB).
- **Нічого не висить у повітрі**: усе стоїть на підлозі ніші (верх `NicheFloor` = **1.2**, не 2.6 — це смуги каменю) або кріпиться до стіни/балки.
- **Неідеально, але не хаотично**: невеликі відмінності (товщина, зсув), але не «рівні кубики» і не «купа кубиків».
- Колір міняти **лише кольором**, матеріал не чіпати.
- Нові моделі руди/кристалів — **брати наші** з `Workspace/OrePrefabs/OrePlot` (жили `_S/_M/_L`, `Chunk*`, `Cut*`), без Creator Store.
- Бюджет префабу: ≤ **4500** деталей (мапа 3 ≈ 4450), ≤ 24 джерела світла, тіні вимкнені.

## 2. Що змінюється на кожній мапі
| Що | Як |
| --- | --- |
| Стіни, стеля, вхід (передня стінка `Decor/Entrance`) | палітра мапи, на пару тонів темніше за мапу 2 (мапа 3: HSV hue 0.62, sat ≥0.12, value × 0.76) |
| Балки / опори | видалити старі, нові рами між плотами (не над ними); балка з 6 шматків, кожен **торкається стелі**; стовпи з 3 частин різної ширини, постаменти, ступінчасті консолі, срібні кільця. Без кристалів на балках |
| Дірки в стелі (CeilingCracks) | прибрати; замість них — жили руди мапи догори дриґом зі стелі + слабке PointLight |
| Дорога | як на мапах 1–2: великі плити (≈26), ширина й центр «гуляють» сходинками, біля ролу — розширення сходинками (не квадрат). **Нижній шар виступає на 1 студс з усіх боків** (контур, розбитий на смуги без накладань). Верх трохи темніший. Без кольорових камінців. Дорога до самої підлоги (верх 2.6, низ 1.2 через основу) |
| Смуги каменю біля плотів (`Floor_stone`) | лишаються прямими й цілими як на мапі 2; підлаштовується дорога (від смуги 1 студс землі + 1 бортик) |
| RollSystem | переносити **цілою моделлю** (PivotTo тимчасової моделі), ніколи по деталях — інакше ламається важіль |
| Дерево в Sell / Workshop | перефарбувати **тільки дерев'яні деталі** в тон мапи (зберігаючи яскравість кожної дошки). NPC, ваги, навіс, голем-коваль, шестерні, піч, руду **не чіпати**. Ящики й палети — **не чіпати** |
| Інші помаранчеві балки (табло, рамка NEXT MAP, вхід, стовпи панелей) | лише колір |
| Плоти | плити підлоги — палітра мапи, випадкове розкладання (кількість та сама, 18), шви; бортики однієї висоти зі світлою смужкою зверху рівно між кутами; кутові стовпчики вищі + срібна плитка + кристал руди мапи (по черзі між плотами). Колізії, Crate, Label, LockedTint, Ores — не чіпати |
| Вивіска входу | нова у темі мапи, опущена на ланцюгах нижче балки; нічого не ховати в текстурі балки |
| Жили руди на стінах | ~14 шт., **розосереджені** (мін. ~22 стади між центрами), рівномірно по висоті (низ/середина/верх по черзі), не перетинаються ні з чим |
| Ліхтарі | підвісні на ланцюгах з балок + настінні на стовпах рам; кристал Neon усередині, **світла не дають**. Наземних ліхтарів не ставити |
| Куточки | тематичні сценки в задніх кутах: вагонетка з рудою на рейках по діагоналі в кут; стійка з детальними інструментами (кірка/лопата/молот з кристалами) + ящик з рудою. Стара мідна кірка — замінити |

- Плити плотів: `5d6680 66708b 566078 6d7894 606a85 5a6584 6a7390`.

## 4. Порядок роботи (зі скрінами після кожного кроку)
1. Копія префабу + чистка (декор попередньої мапи, зелень, руда на стінах, CeilingCracks).
2. Дорога + перенесення RollSystem + підгонка під смуги каменю.
3. Рами / балки → стеля (кристали) → затемнення стін, стелі, входу.
4. Sell / Workshop (лише дерево) + інші балки.
5. Плоти (спершу плот 1 на затвердження, потім 2–6).
6. Вивіска, жили на стінах, ліхтарі, куточки.
7. Перевірка перетинів і «літаючих» деталей, кількість деталей.
8. `MAX_STAGE` + тест переходу в Play + синк.
