# План — 3 ексклюзивні големи для тижневих нагород

> [!success] Стан (04.11.2026)
> Тижневі големи у грі: [[Mushroom Golem]], [[Honey Golem]], [[Snow Golem]], [[Cloud Golem]] (дні 7 / 14 / 21 / 28 Daily).

← [[Plans]] · [[Golems]] · [[Plan - Exclusive Case Golems]] · [[Mushroom Golem]] · [[Golem Stats - Miner]]

Потрібні ще три ексклюзивні големи для щоденних нагород (DAILY REWARDS). Зараз кожен 7-й день дає Mushroom Golem-носія. Нові големи мають бути простенькі, на рівні Mushroom: без особливих трюків, аур і нових видів анімацій.

## Як зараз працює 7-й день
- `Shared/DailyConfig`: `GOLEM7 = { kind = "golem", key = "mushroom", cls = "carrier" }` — один і той самий голем на днях 7, 14, 21, 28…
- `Config.label` для голема завжди повертає «Mushroom Golem».
- Mushroom: `exclusive = "group"`, `dynamic = "bestMiner"`. Сила — частка найкращого звичайного голема гравця: майнер 50 %, носій 75 %. Швидкість 1.1, `size = 1.05`.

## Рішення (02.11.2026): тижневий цикл із 4 големів
Цикл на 28 днів, далі повторюється. Mushroom лишається першим тижнем.

| День (n mod 28) | Голем | Клас (нагорода) | Частка best | Швидкість | size | Префаб (x) |
| --- | --- | --- | --- | --- | --- | --- |
| 7 | Mushroom (вже є) | Carrier | 75 % | 1.1 | 1.05 | −1163 (перенесено) |
| 14 | **Honey Golem** | Miner | **65 %** | 1.15 | 1.05 | −1173 |
| 21 | **Snow Golem** | Carrier | **90 %** | 1.2 | 1.1 | −1183 |
| 28 | **Cloud Golem** | Miner | **150 %** | 1.3 | 1.15 | −1193 |

*Рішення: усі тижневі стоять **за кейсом** (кейс x −1143), платформу `PlotPrefabs/Stand` подовжено до x −1206. У всіх трьох — анімації `fx`. `DailyConfig.WEEKLY` уже в грі: поки Snow / Cloud немає в каталозі, їхні дні дають Mushroom.*

- **Швидкість і size** — пропозиція: трохи зростають до 4-го тижня. Їх можна змінити.
- **Cloud (150 %)** сильніший за Coral, Jade і Storm із кейсу (65 / 100 / 125 %), слабший за Phantom і Chrono (160 / 200 %). Це головна нагорода 4-го тижня — гравцеві є заради чого повертатися.
- **Частка best** однакова для всіх трьох класів голема (`share` = `carrierShare` = `warriorShare`). В адмін-панелі можна видати будь-який клас.
- **Звідки отримати** (`how` / `howShort`): «Weekly reward» / «Weekly» — лише для класу нагороди, для інших — `nil`.
- **`exclusive = "weekly"`**. Нові големи додаються в `M.EXCLUSIVES` після `mushroom`, перед големами кейсу: `{ "mushroom", "honey", "snow", "cloud", "coral", … }`. Index покаже їх у групі Exclusive.
- **Повтор:** через 28 днів голем випадає ще раз — це дублікат. `ResetForNewMap` зберігає всіх `exclusive`.

## Три големи
### Honey Golem — 14-й день, Miner, 65 % — ✅ зроблено 02.11.2026 ([[Honey Golem]], x −1173)
- **Кольори:** мед `#e8a93a`, темний мед `#a8641e`, віск `#f6d77a`, коричневі смуги `#4a2f1a`; Neon — немає (або ледь світна крапля меду).
- **Тіло:** бурштинове, з темними смугами на корпусі, як у бджоли. На спині — дерев'яний **бочонок меду** з крапелькою. Над плечем **бджілка** — вільна деталь, `bob` (єдиний `fx`). Ріжки-вусики на голові.
- **Інструменти:** шаблонна кірка — дерев'яний держак, голова кольору меду, на голові крапля. Меч шаблонний, лезо кольору воску.
- **Ящик:** вулик-скриня — світлі дерев'яні дошки, рівний обідок, соти на боці (шестикутник із блоків, без «+»), однакові ручки-планки.

### Snow Golem — 21-й день, Carrier, 90 % — ✅ зроблено 02.11.2026 ([[Snow Golem]], x −1183; Mushroom-носій тепер теж «Weekly reward»)
- **Кольори:** сніг `#f1f5fa`, тінь снігу `#c9d6e6`, шарф `#d94a4a` (приглушений червоний), морква `#f08a2c`, відро `#5a6878`, гілочки `#5b3f2a`.
- **Тіло:** три «грудки» — таз, корпус, голова, трохи округлені ступенями. Червоний **шарф** зі звисаючим кінцем (`sway` — за бажанням). **Відро** на голові, **морквяний ніс**, вугільні ґудзики на грудях. На плечах гілочки — без хреста, дві гілочки під кутом.
- **Інструменти:** кірка з льодяною головою (блакитна), меч-бурулька (шаблон, світло-блакитний).
- **Ящик:** санки-скриня — дерев'яний ящик на двох полозах, рівний обідок, однакові ручки-мотузки.
- **Увага:** білий не повинен сліпити — без Neon, сніг трохи сіро-блакитний.

### Cloud Golem — 28-й день, Miner, 150 % — ✅ зроблено 02.11.2026 ([[Cloud Golem]], x −1193)

**Усі 3 тижневі големи готові, цикл `DailyConfig.WEEKLY` повний** (7 Mushroom · 14 Honey · 21 Snow · 28 Cloud).

### Допрацювання (02.11.2026)
- **Календар Daily:** плитки тижневих днів (7 / 14 / 21 / 28 …) більше не закриті «?» — видно голема й назву навіть за межами 7 відкритих (`DailyWindow`: `hidden = i > VISIBLE and not seventh`).
- **«65% BEST»:** для всіх ексклюзивів з `dynamic` над рідкістю зжовтий рядок частки best саме цього класу (`GolemCatalog.bestShare` / `bestText`): табличка голема в руці (`HeldItemService`), картка «YOU GOT!» кейса, підказка хотбара. Mushroom: майнер 50 %, носій 75 %.
- **Кейс:** падає лицем (емблемою) до гравця — був розвернутий спиною (+180° у `CaseOpenClient`).
- Бекапи — `NicheBackup/BestLabel_v1_*`.

- **Кольори:** хмара `#eef3fb`, тінь хмари `#c3d3ea`, небо `#7fb6ff`, щічки `#ffb3c7`, веселка — 5 приглушених кольорів (червоний, помаранчевий, жовтий, зелений, блакитний).
- **Тіло:** пухке, з «хмарних» блоків різного розміру. Плечі й голова — купчасті хмаринки. На спині маленька **веселка** — дуга зі сходинок-блоків, кольори рядами, не хрест. - **Інструменти:** кірка з голівкою-хмаринкою, меч із блакитним лезом і хмаринкою на гарді.
- **Ящик:** блакитна скриня з хмаринками на боках, рівний білий обідок, однакові ручки-хмаринки.
- **Увага:** білий і веселка не мають сліпити — без Neon, кольори веселки приглушені.

## Рівень деталізації (як Mushroom)
- **Тіло:** ~55–70 блоків, 4–5 своїх кольорів + спільні (світлий, темний, щічки), ≤ 850 трикутників, Neon — максимум 1 акцент.
- **Обличчя:** веселе — рівні підняті брови, усмішка.
- **Інструменти:** шаблонні `PICK` / `SWORD`, перефарбовані, + 1–2 тематичні деталі. Без нових типів мечів, без хитання частин.
- **Ящик:** власний простий: тематичний колір, рівний обідок, однакові прості ручки, без лави.
- **Анімації:** стандартні кліпи. Максимум 1 простий `fx` (наприклад `sway` листочка) — за бажанням.
- **Без аури** і без `PointLight`.
- **Спільні правила:** без щілин, нічого не висить у повітрі, правило 0,1, без «+»-хрестів, ніщо не сліпить, стопи на плиті.

## Що треба в коді
1. **`GolemCatalog`:** 3 записи на кшталт Mushroom:
   - `rarity = "Exclusive"`, `exclusive = "weekly"`, `odds = 0`, `dynamic = "bestMiner"`;
   - `share` / `carrierShare` / `warriorShare`, `how` / `howShort`;
   - бекап у `NicheBackup`.
2. **`DailyConfig`:** замість `GOLEM7` — список `WEEKLY = { {mushroom, carrier}, {honey, miner}, {snow, carrier}, {cloud, miner} }`. `reward(n)` бере `WEEKLY[((n / 7 − 1) mod 4) + 1]`. `Config.label` для голема бере назву з каталогу.
3. **`DailyWindow`:** плитка 7-го дня показує правильного голема (іконка — `ItemViewport.golemKey`). Перевірити, що вона не завжди Mushroom.
4. **`DailyService`:** видача вже йде через kind `golem` — перевірити, що бере `key` і `cls` з нагороди.
5. **Префаби:** `PlotPrefabs/<Name>Golem`, `…Pickaxe`, `…Sword`, `…CarryBox` — за кейсом: Mushroom x −1163, Honey −1173, Snow −1183, Cloud −1193.

## Порядок робіт
Для кожного голема повний цикл, як завжди:
1. генератор;
2. збірка в Studio (`GolemBuilder`);
3. каталог;
4. Play-тест: плот, носій, воїн у руці, Index;
5. нотатка й рядки в таблицях.

Порядок: Honey → Snow → Cloud. Потім `DailyConfig` / `DailyWindow` і тест циклу: дні 7, 14, 21, 28, 35 → Mushroom, Honey, Snow, Cloud, Mushroom.
