# Server

← [[My Mining Golems - Scripts|Scripts]]

Script — серверні скрипти.

| Файл | Де в Roblox | Що робить |
| --- | --- | --- |
| `NicheService.lua` | `ServerScriptService/NicheService` (ModuleScript) | ніші гравців: на старті переносить шаблони з `Workspace/NichePrefabs` у `ServerStorage`, збирає 6 ніш у сокетах `Workspace/NicheSockets` (вільна ніша = мапа 1, порожня), видає гравцю першу вільну нішу, телепортує на `PlotSpawn` при кожній появі персонажа, скидає нішу, коли гравець виходить. Ніша видається, коли `DataService` завантажив дані (мапа із збереження); перед скиданням ніші знімає знімок даних (`DataService.Capture`). API: `GetNiche(player)`, `GetOwner(niche)`, події `Claimed` / `Released` |
| `DataService.lua` | `ServerScriptService/DataService` (ModuleScript) | збереження даних гравця (DataStore): сесійний замок, завантаження при вході, автозбереження 60 с, збереження при виході й закритті сервера, секції для складних даних (Forge), `ResetStageScope` для переходу на мапу. Дані — атрибути гравця (`ATTRS`, `PREFIXES`) і секції. API: `WaitLoaded`, `GetData`, `GetSection`, `RegisterSection`, `SaveNow`, `Capture`, `ResetStageScope`. У Studio без доступу до API працює сховище в пам'яті. Розділ 21 GDD |
| `MultiService.lua` | `ServerScriptService/MultiService` (ModuleScript) | рахує глобальний множник Money: друзі на сервері, ребіти, донат x2 Money, VIP, мапа (числа — `Shared/MultiConfig`); пише атрибути `Multi_<джерело>` і `TotalMulti`. API: `Get(player)`, `Apply(player, сума)` (множить і округлює) |
| `MonetizationService.lua` | `ServerScriptService/MonetizationService` (ModuleScript) | покупки за Robux: `ProcessReceipt` для ступенів x2 Money (дублікати за `PurchaseId`, збереження перед підтвердженням), перевірка геймпасів при вході → атрибути `Pass_*`. ID — `Shared/MonetizationConfig` |
| `NicheBoot.lua` | `ServerScriptService/NicheBoot` (Script) | запускає по черзі `DataService`, `MultiService`, `MonetizationService`, `NicheService`, `ForgeService`, `RollScreenService`, `RollUpgradeService`, `SellService`, `InventoryService`, `PlotService` (`Start()`); `DataService` — першим |
| `ForgeService.lua` | `ServerScriptService/ForgeService` (ModuleScript) | кузня Forge у кожній ніші: стан (сон / пробудження / робота), віддана для пробудження руда, піддони Ore / Bars, переплавка: удар раз на `spdOf(SpdLvl)` с, за удар — до `ophOf(OphLvl)` руди (Ore per Hit), злитки зараховуються в кінці інтервалу, покращення з кліку по екрану табла. Дії гравця — RemoteEvent `Remotes/ForgeAction` (Give, Wake, Put — вся руда, що влізе, PutOre — `{ ore, n }`: одна руда в потрібній кількості (перевіряє тип, число, запас гравця й місце на піддоні в $), Take, TestOre, Upgrade + `"Cap"` / `"Spd"` / `"Oph"`). Стан кузні (і `OphLvl`) зберігається (секція `Forge`) і відновлюється при вході. «Take» кладе злитки в інвентар (`Bars_*`), продаються в лавці Sell (`ForgeConfig.TEST_SELL_BARS = false`). **Тест:** руда, злитки й гроші — атрибути гравця `Ore_*`, `Bars_*`, `Money` |
| `RollScreenService.lua` | `ServerScriptService/RollScreenService` (ModuleScript) | табло Roll Upgrades у кожній ніші: власник зупинився в невидимій зоні 11 стадів від важеля ролу й стоїть нерухомо 0,25 с → атрибут `RollUpgradeScreen.Open = true`; рух скидає таймер, тож на ходу табло не падає; 1 с поза зоною → `Open = false`. Радіус і час — атрибути `ZoneRadius`, `HoldTime` |
| `SellService.lua` | `ServerScriptService/SellService` (ModuleScript) | продаж у лавці Sell: RemoteEvent `Remotes/SellAction` — `("Sell", { Ore_Coal = n, Bars_Iron = n, … })`; перевіряє власника ніші, коло лавки (`SellRig.RING_R` + 2,5), кількості (ціле, не більше запасу), паузу 0,3 с; заблоковане в інвентарі (`InvLocks`) не продає; знімає руду / злитки, додає `Money` (× `TotalMulti`), ставить `Sell.SellAmount` і збільшує `Sell.SellSeq` (анімація продажу) |
| `InventoryService.lua` | `ServerScriptService/InventoryService` (ModuleScript) | інвентар: хотбар — список без дірок до 9 (`Hold` ключа додає слот у кінець, `Hold` "" прибирає слот того, що було в руці; те, що закінчилось, зникає), предмет у руці, замки, видалення. `Remotes/InventoryAction`: `Delete` (заблоковане й големів на плотах — `PlotPlaced` — пропускає), `Lock` `{ keys, on }`, `Hotbar` (список ключів), `Pin` `{ key, on }` (закріплений слот лишається після Put Away), `Clear` (ключі — «в інвентар»), `Hold`. Атрибути `InvGolems`, `InvLocks`, `InvHotbar`, `InvPinned`, `InvHeld`, `Pot_*`; секція `Inventory` у DataService. **Тест:** у Studio без збереження — тестові големи (`{ id, kind, cls }`, 3 носії) й зілля |
| `PlotService.lua` | `ServerScriptService/PlotService` (ModuleScript) | плоти (зони фарму, Interactive Objects → Plots): спавн руди на 5 точках (`spawnOf`, шанси як ваги), HP, майнери (лише вільна руда, удар у темп кліпу Mine), шматки руди на підлозі й стаки ×N, носій (збирає, висипає в ящик плоту → `Ore_*` гравця), рух големів атрибутами (`MoveFrom` / `MoveTo` / `MoveT0` / `MoveDur`, `Look`). `Remotes/PlotAction`: `Place` `{ plot, slot, id }`, `EquipBest`, `Upgrade` (`Plots` / `Spawn` / `Slots` / `Carry`). Атрибути гравця `PlotLv`, `PlotAssign`, `PlotPlaced`; секція `Plots` (скидається на новій мапі). **Тест:** у Studio без збереження — Equip Best з тестових големів |
| `RollUpgradeService.lua` | `ServerScriptService/RollUpgradeService` (ModuleScript) | покупки на табло Roll Upgrades: RemoteEvent `Remotes/RollUpgrade` (`"Luck"` / `"Stands"`), ціна з `RollConfig`, перевірка й списання `Money`, атрибути гравця `RollLuckLvl`, `RollLuck`, `RollStands` (беруться із збережених даних). Підставки ролу: ставить `Prefabs/RollStand` у точки `RollSystem/StandPoints/Point1…5` стільки, скільки куплено (вільна ніша — 1), нова виринає з підлоги |
| `RollRoleService.lua` | `ServerScriptService/RollRoleService` (Script) | вибір типу голема на станції ролу: `Remotes/RollRole` (`"Miner"` / `"Carrier"` / `"Warrior"` — лише `Stage >= 2`), не частіше раз на 0,2 с → атрибут гравця `RollRole` (зберігає DataService) |
| `CaveEntrance.lua` | `ServerScriptService/CaveEntrance` (Script) | підказка `CavePrompt` у ніші → телепорт на `GolemCaveSpawn` (поки точки немає — нічого) |

Видобуток руди — `PlotService` (руда спавниться лише на плотах власника ніші).

**Оновлено 25.10.2026:** `DataService` — новий збережений атрибут `RollRole` (global, `Miner`); `ForgeService` — вугілля не плавиться, пробудження знімає `WAKE_MONEY`, заблоковане в інвентарі не кладеться; `PlotService` — `Upgrade` не продає закриті картки (`cardOpen`). Копії `.lua` у цій папці оновлено зі Studio.
