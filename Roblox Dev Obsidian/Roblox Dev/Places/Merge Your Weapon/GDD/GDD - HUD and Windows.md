# GDD - HUD and Windows

← [[Merge Your Weapon - GDD|GDD]]

Інтерфейс: HUD, вікна, інвентар. Кожне вікно потім отримає свою нотатку в 2D.

## HUD
| Де | Що |
| --- | --- |
| Зверху (на базі) | **Base**, **Fight** |
| Зверху (у забігу) | поточна зона і прогрес мобів («ZONE 1  3/5») |
| Знизу (у забігу) | синя кнопка **RETURN** над HP і стаміною — назад на плот |
| Зліва | **Shop**, поруч **Upgrades** (червоний бейдж — скільки апгрейдів можна купити); також **Index**, **Rebirth** |
| Справа | **x2 CASH** — наступний ступінь драбини x2 … x1024 і ціна в Robux (`GDD - Shop and Passes`) |
| На базі | **Buy Weapon** (тір і ціна поточної покупки) |
| Внизу | гроші, HP, стаміна, хотбар інвентаря |
| Справа (у забігу, план) | 3 слоти розхідників один під одним; клік — використати / вибрати розхідник (`GDD - Supplies`) |
| Над хотбаром (план) | іконка бронежилета, поки активна броня; на HP-барі — синя смуга броні |

## Вікна
| Вікно | Опис |
| --- | --- |
| Shop | паки, паси, набори зброї; кнопка GIFT! — див. `GDD - Shop and Passes` |
| Gift | подарунок іншому гравцю — [Gift Window](obsidian://open?vault=Roblox%20Dev&file=Places%2FMerge%20Your%20Weapon%2F2D%2FGift%20Window%2FGift%20Window) |
| Upgrades | дерево шестикутників, див. `GDD - Upgrades` |
| Index | колекція зброї, див. `GDD - Weapons and Merge` |
| Rebirth | див. `GDD - Rebirth` |
| Inventory | кастомний інвентар у стилі стандартного Roblox |

## Інвентар
- Кастомний, у стилі стандартного інвентаря Roblox: хотбар 1–0 внизу + вікно з вкладками (сундуки, …) і пошуком.
- Однакові сундуки складаються в стак з лічильником (x5, x2…).

![[MYW ref - inventory.png]]

## Повідомлення
- «На плоті немає місця» — при покупці або відкритті сундука, коли плот повний.

## Правила
- Тексти — під автопереклад Roblox: числа й таймери окремими `TextLabel` з `AutoLocalize = false`.

## Анімації HUD
- Купюри / геми летять зі світу в свої лічильники внизу зліва, лічильник підстрибує; сундук — 3D-коробкою в рюкзак.
- Смуги HP і стаміни плавно доїжджають до значення.
