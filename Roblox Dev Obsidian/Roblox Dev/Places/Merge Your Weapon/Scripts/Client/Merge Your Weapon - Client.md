# Client

← [[Merge Your Weapon - Scripts|Scripts]]

LocalScript у `StarterPlayerScripts`. Оновлено 2026-11-15.

| Скрипт | Що робить |
| --- | --- |
| `HUDController` | HUD, DROP, бейдж UPGRADES, кнопка x2 CASH (ціна, Cash Burst, MAX) |
| `WeaponClient` | показ зброї (над головою, руки вгору), дотик, DROP на Q, VFX і звуки; анімує тільки свою зброю в бою |
| `FightFx` | снаряди, хіти, цифри урону (стак на моба), камера на старті бою |
| `MobClient` | тіла своїх мобів: спавн, AI, атака, ragdoll, HP бар, таймер відродження, анімація лікування, слоу-мо туторіалу |
| `MobAmbience` | гарчання / стогін своїх зомбі |
| `CashDropController` | купюри, геми, сундуки на землі (тільки свої), підпис «+N», політ у HUD |
| `CratePopController` | анімація відкриття сундуків (до 8 колом) |
| `TutorialController` | затемнення, піднята кнопка, курсор, доріжка, урок «не стій» |
| `SprintController` | спринт і стаміна |
| `BackpackController` | Backpack |
| `ShopController` | Shop Window, плашки знижок |
| `GiftController` | Gift Window |
| `PassStandController` | Slot Stand: зброя, табличка, OWNED |
| `IndexController` | Index Window |
| `RebirthController` | Rebirth Window |
| `UpgradesController` | Upgrades Window |
| `SettingsController` | Settings Window |
| `CodesController` | Codes Window |
| `LobbyMusicPlayer` | музика лобі (атрибут `IsMusic`) |
| `SupplyIdleAnimator`, `TraderIdle`, `WindmillAnimator` | декор: анімації NPC і вітряка |
