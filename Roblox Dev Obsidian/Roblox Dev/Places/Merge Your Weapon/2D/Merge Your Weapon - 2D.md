# 2D

← [[Merge Your Weapon]]

Інтерфейс, іконки, текстури. Спільний стиль вікон — модуль `UIKit` (шрифт Luckiest Guy, обведення `#040435`, глянцеві плашки, вікно = шапка + тіло + X + затемнення + розмиття; клік усередині вікна не закриває його). Вікна відкриваються через `ReplicatedStorage/UIOpen:Fire("<Name>")`.

| Елемент | Що це |
| --- | --- |
| [[HUD]] | головний екран: стани Plot / Lobby / Zone, BASE / FIGHT, бокові кнопки, гроші, хотбар, BUY WEAPON, DROP |
| [[Shop Window]] | вікно SHOP: паки, геймпаси, набори зброї, кнопка GIFT |
| [[Index Window]] | колекція зброї: 21 картка по тірах, силуети невідкритих, прогрес |
| [[Rebirth Window]] | ребьорт: поточний бонус, вимога, нова зброя тінню |
| [[Upgrades Window]] | дерево апгрейдів з шестикутників на весь екран |
| [[Settings Window]] | налаштування: музика, звуки, назви зброї, ефекти |
| [[Codes Window]] | введення кодів |
| [[Supply Shop Window]] | магазин розхідників за Gems: запас свій у кожного, рестік кожні 30 хв |
| [[Gift Window]] | подарунки іншим гравцям: вибір гравця і подарунка |
| [[Backpack]] | власний рюкзак: кнопка у верхній панелі Roblox, хотбар, панель з категоріями |
| [[Weapon Tags]] | таблички «Name · Tier N» над зброєю і VFX мерджу |
| [[Icons]] | ID іконок і шестикутників |
| [[Textures]] | текстури поля |
