# OSIRIUS


← [[Roblox]]

Наша студія (**OSIRIUS**, до 27.10.2026 — OREKO). Від її імені публікуємо всі плейси. Тут лежить усе, що несе бренд і **однакове в кожній грі**: назва, логотип, загрузочний екран.

| Нотатка                  | Що це                                                                                                                                                                                          |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[OREKO Loading Screen|OSIRIUS Loading Screen]] | загрузочний екран «MADE BY OSIRIUS»: кірка розбиває камінь, під ним золоте OSIRIUS, далі шкала завантаження; звук ударів кірки, музика плейсу — від 50 % шкали (`SoundService.LoadingMusicOK`) |

## Бренд
| Що | Значення |
| --- | --- |
| Назва | **OSIRIUS** (одне слово, капсом; до 27.10.2026 — OREKO) |
| Шрифт | Montserrat Heavy / 900 |
| Назва на логотипі | золотий градієнт `fff6b0 → ffd23a → ff9a1a` (згори вниз), контур `14161a`, темна тінь `0c0e12` |
| Підпис | «MADE BY» на держаку кірки, читається як «Made by OSIRIUS» |
| Стиль | стиль A: товстий чорний контур, studs-візерунок «L + квадратик» |

> [!info] Правило
> Логотип і назву **не змінюємо** між плейсами. У кожному плейсі можна міняти тільки оточення: фон, кольори шкали, швидкість. Як саме — у [[OSIRIUS Loading Screen|OSIRIUS Loading Screen]].

## Історія
- назва студії в лого: OREKO → OSIRIUS (27.10.2026)
- звук ударів кірки в лого + музика від 50 % шкали (27.10.2026)
- тріск каменю (`RockBreak`) на третьому ударі в лого (27.10.2026)
