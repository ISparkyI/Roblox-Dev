# OREKO

← [[Roblox]]

Наша студія. Від імені OREKO публікуємо всі плейси. Тут лежить усе, що несе бренд і **однакове в кожній грі**: назва, логотип, загрузочний екран.

## Бренд
| Що | Значення |
| --- | --- |
| Назва | **OREKO** (одне слово, капсом) |
| Шрифт | Montserrat Heavy / 900 |
| Назва на логотипі | золотий градієнт `fff6b0 → ffd23a → ff9a1a` (згори вниз), контур `14161a`, темна тінь `0c0e12` |
| Підпис | «MADE BY» на держаку кірки, читається як «Made by OREKO» |
| Стиль | стиль A: товстий чорний контур, studs-візерунок «L + квадратик» |

> [!info] Правило
> Логотип і назву **не змінюємо** між плейсами. У кожному плейсі можна міняти тільки оточення: фон, кольори шкали, швидкість. Як саме — у [[OREKO Loading Screen]].
